# Maximum Vehicle Speed

`speedMax`

> Stores the numeric value shown as **Max Speed** in the VEH form.

## Foundry support

Foundry parses this key as a floating-point value and writes it back as `speedMax`.
The visual label is an editor description; it does not establish units, safe
ranges, or an engine default.

## Verification status

Gameplay scaling, type-specific interpretation, and omitted-field behavior are
not verified here against a named engine revision. Test authored values in the
target game build.
