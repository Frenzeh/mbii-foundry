# MIRV Cluster Volley

`MB_ATT_MIRV`

> Controls volley payload count for the MIRV Launcher.

## What it does

Increases the number of rockets fired in a single volley: $1 + \text{Rank}$.

## Valid Values

- **Rank 1:** 2 rockets per volley.
- **Rank 2:** 3 rockets per volley.
- **Rank 3:** 4 rockets per volley.
