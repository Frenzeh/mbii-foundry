# Quad 3 (Q3 Saber Deflect)

`CFL_HASQ3`

> Allows a saberist to block incoming blaster shots during attack swings.

## What it does

Historically known as Quad 3 in Open Mode. Allows a saber user to deflect and block incoming blaster projectiles while in active swing animations, provided their Resource / BP is not depleted.
